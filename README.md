# Credex AI Spend Audit

An AI-powered SaaS optimization dashboard that helps teams identify unnecessary AI tool spending and discover cost-saving opportunities.

## Live Demo

https://credex-ai-spend-audit-murex.vercel.app/

---

## Features

- AI spend audit engine
- Dynamic savings calculation
- Animated analytics counters
- AI optimization insights
- Confidence score system
- Downloadable audit reports
- Futuristic SaaS UI
- Responsive dashboard design

---

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel
