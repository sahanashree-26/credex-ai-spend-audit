## Summary

Credex AI Spend Audit is a frontend-focused AI SaaS optimization dashboard prototype designed to help teams estimate potential savings from AI tool subscriptions.

The project was built using:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

---

## Key Features

- AI audit engine
- Savings calculations
- Dynamic dashboard UI
- AI confidence scoring
- Downloadable reports
- Futuristic SaaS-inspired interface

---

## Important Note

This project is currently a frontend prototype and uses heuristic-based estimation logic rather than real billing integrations.
