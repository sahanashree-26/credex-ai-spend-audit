# USER_INTERVIEWS

# User Conversations

I did not complete formal structured user interviews during this project.

However, I discussed the idea informally with:

- one student interested in AI tools
- one friend using ChatGPT and Copilot regularly

---

# Main Feedback

## Feedback 1

The dashboard UI felt modern and visually interesting compared to basic cost calculators.

## Feedback 2

The savings estimates were understandable, but users wanted more personalized recommendations tied to actual usage patterns.

## Feedback 3

The downloadable report feature made the product feel more realistic and professional.

---

# What I Would Improve

With more time, I would conduct:

- structured founder interviews
- engineering team interviews
- SaaS spending workflow analysis

to better validate real pain points around AI subscription management.
