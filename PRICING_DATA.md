# PRICING_DATA

## Pricing Assumptions

The audit engine currently uses simplified pricing assumptions based on publicly known subscription tiers for popular AI tools.

---

## Example Tool Assumptions

| Tool            | Estimated Monthly Cost |
| --------------- | ---------------------- |
| ChatGPT Plus    | $20/user               |
| Claude Pro      | $20/user               |
| GitHub Copilot  | $10/user               |
| Cursor Pro      | $20/user               |
| Gemini Advanced | $20/user               |

---

## Savings Logic

The application estimates optimization opportunities using:

- spend thresholds
- team size
- likely unused seats
- overlapping tool usage assumptions

---

## Current Limitation

The project does not yet connect to:

- real billing APIs
- token usage data
- actual invoice systems

All outputs are estimation-based for demonstration purposes.
