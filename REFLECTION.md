# REFLECTION

## What went well

The biggest success in this project was successfully building and deploying a complete SaaS-style frontend application despite being new to Next.js and TypeScript. I was able to break the UI into reusable components and gradually improve the product visually and functionally.

The deployment process also helped me understand how modern frontend products move from local development into production.

---

## What was difficult

The hardest part was debugging TypeScript and JSX issues while trying to connect multiple components together. I also struggled with React rendering warnings caused by Math.random usage inside render functions.

Understanding how props, state, and component architecture work together took significant time.

---

## What I would improve next

If I had more time, I would improve the actual audit intelligence layer.

Currently the recommendations are heuristic-based and use simple spend thresholds. I would build:

- API usage ingestion
- real billing analysis
- usage trend tracking
- team-level optimization insights

I would also add authentication and persistent report history.

---

## Biggest lesson learned

Frontend polish matters more than I initially expected.

Animations, spacing, visual hierarchy, and product feel changed the perceived quality of the application significantly even before adding advanced functionality.

I also learned that debugging is a major part of real development work.
